# Trker (short for tracker) is a simple and fast web analytics tool that helps you track and analyze user behavior on your website. It provides insights into how users interact with your site, allowing you to make data-driven decisions to improve user experience and increase engagement.


## Tech Stack
- C# and MVC for backend development
- JavaScript and React for frontend development
- MongoDB 
- Visual Studio 2026
- Windows machine for development and testing
- docker for containerization and deployment
- github actions for CI/CD

## Features
- Real-time tracking of user behavior on your website
- Cookie-less tacking for privacy compliance
- Minimal and lightweight design for fast performance
- Minimal code and simple features for now

## UI/UX
- Clean minimal design 
- Body font: Geist font with -0.15px letter spacing and Heading font: Geist Mono
- Dark theme: 1C1C1C as dark background color E5E5E5 for white text and A1A1A1 for subtle text 
- Light theme: #E5E5E5 as light background color. Build a hierarchy with #292929 , #5D5D5D , #9E9E9E 
- Icon Size: 14px for navigation and 20px for cards
- Phospor Icons for sleek icons, always
- Border radius: 6px, 8px, and 12px
- Micro Interactions and subtle animations with less than 200ms duration
- Primary button design: 1. Drop shadow: Opacity 20%, y 3, blur 6px 2. Inner shadow: Opacity 24% blur 6 and spread 2 and 3. Drop shadow: Primary color with 100 opacity and spread is 1.
- Create a consistent design system with reusable components and styles under a components folder

## Guidelines
- Minimal code and simple features for now
- Camel Case naming convention for variables and functions
- Readable code 
- Strongly follow SOLID principles
